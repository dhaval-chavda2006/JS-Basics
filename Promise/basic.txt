### execution context of Javascript

- executes one line of code at a time, it has a call stack which keeps track of the function calls and their execution order. When a function is called, it is added to the call stack, and when it returns, it is removed from the stack.

- memory heap is where the variables and objects are stored in memory. When a variable is declared, it is stored in the memory heap, and when it is no longer needed, it is removed from memory.

### Blocking and Non-Blocking Code

Blocking code is code that stops the execution of other code until it is finished. For example, if you have a long-running function that takes a few seconds to complete, it will block the execution of other code until it is done.

Non-blocking code, on the other hand, allows other code to run while it is executing. This is achieved through asynchronous programming techniques such as callbacks, promises, and async/await.

inside fetch whatever promise queue is there same inside there will be callback queue, which is a queue of functions that are waiting to be executed. When the promise is resolved, the callback function is added to the callback queue, and when the call stack is empty, the event loop picks up the next function from the callback queue and adds it to the call stack for execution.
